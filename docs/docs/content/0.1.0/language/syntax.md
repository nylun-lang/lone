# Basic Syntax (v0.1.0)

Lone v0.1.0 introduced the initial grammar rules:

## Variables

```rust
var count: i32 = 10
var ratio: f32 = 1.5
var active: bool = true
```

## Literals

- Numbers: integers (`123`), floats (`4.56`)
- Strings: `"text with escape characters\n"`
- Booleans: `true`, `false`
