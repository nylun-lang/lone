# Introduction to Lone (v0.1.0)

::: tip Historical Documentation
This is the documentation for Lone v0.1.0. For the latest features including MIR, loops, and runtime adapters, view [v0.2.0 (latest)](/content/latest/guide/introduction).
:::

Lone v0.1.0 introduced the foundational syntax and PEG parser for the Lone language:
- Basic variable definitions (`var x: i32`)
- Primitive types
- Function declarations (`fn add(a: i32, b: i32) i32`)
- Abstract syntax tree (AST) representation
