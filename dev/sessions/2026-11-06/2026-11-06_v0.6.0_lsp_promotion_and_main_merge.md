## 2. Technical Implementation Details

### 2.1 LSP Modernization (`pkg/lone-lsp`)
- Authored `protocol.go` implementing standard JSON-RPC 2.0 structures for:
  - `InitializeParams`, `InitializeResult`, `ServerCapabilities`
  - `DidOpenTextDocumentParams`, `DidChangeTextDocumentParams`, `DidSaveTextDocumentParams`
  - `PublishDiagnosticsParams`, `Diagnostic`, `Range`, `Position`
  - `HoverParams`, `Hover`, `MarkupContent`
  - `DocumentSymbolParams`, `DocumentSymbol`, `SymbolKind`
- Authored `server.go` maintaining an in-memory document cache and responding to LSP requests:
  - Parses source via `loneparser.Parse` and type-checks with `loneanalyzer.AnalyzeSource`.
  - Publishes 0-indexed byte-accurate diagnostics to the client.
  - Generates hierarchical document symbol outlines from AST declarations.
  - Provides type hover tooltips and definition locations.
- Comprehensive unit tests in `server_test.go` covering initialization, diagnostics publication, document symbols, and hover.

### 2.2 Greenfield Promotion & Legacy Retirement
- Atomic directory migration:
  - Legacy `pkg/` removed $\rightarrow$ `pkg2/` renamed to `pkg/`.
  - Legacy `cmd/` removed $\rightarrow$ `cmd2/` renamed to `cmd/`.
  - Legacy `libraries/` and `lib2/` removed $\rightarrow$ `lib2/` renamed to `lib/`.
  - Legacy `test/` removed $\rightarrow$ `test2/` renamed to `test/`.

- Replaced all `"lone/pkg2/..."` imports across all packages with `"lone/pkg/..."`.
