## 2. Technical Decisions & Implementations

### 2.1 Status of `lone debug`
- **CLI v1 (`cmd/lone`)**: Fully implemented!
  - `lone debug <scope>`: Dumps structs, sizes, alignments, field offsets, constructors, inherent methods, globals, and locals count.
  - `lone debug <scope> <symbol>`: Targeted lookup of specific symbols with scoped syntax (`main:game`, `main.guess`).
  - Supports `--json` flag for IDE/tooling integration.
- **CLI v2 (`cmd2/lone`)**: Not yet ported. Currently implements `build`, `check`, `parse`, and `version`.

### 2.2 Authored `exemple/guess_v0.6.0.lone`
The new example showcases the entire v0.6.0 feature matrix:
1. **Module Imports**: `import .print, .println, .read_line, .parse_int, .random_range from :std:io`.
2. **Canonical Initialization**: `var game = Game::(100)` backed by struct-associated `pub fn __init__(max_num: i32) Game`.
3. **Encapsulation & Field Modifiers**:
   - `ro _secret: i32`: Private to struct module/methods, immutable from exterior.
   - `ro max_val: i32`: Public read-only field.
   - `attempts: i32`: Mutable state.
4. **Explicit Reference Mutation**: `pub fn check(self: ref<Game>, guess: i32) i32` modifying `self.attempts` in-place.
5. **Interface Data Contracts**: `pub type IfcGameSession = interface { ro max_val: i32, attempts: i32 }`.
6. **Generic Constraint Satisfaction**: `pub fn print_session_status<T where { T satisfies IfcGameSession }>(session: ref<T>) void`.
7. **Grouped Declarations**: `let [min_val, surrender_code]: i32 = 0`.
8. **Sized Buffer Pointers & Typestate Indexing**: `var history: [10]int = ...`, `var hist_ptr: ptr<[10]int> = &raw history`, and `hist_ptr[i] = guess`.
9. **Native Formatted String Interpolation**: `println(f"-> Too low! Try a higher number than ${guess}.\n")`.

### 2.3 Compiler & Standard Library Refinements (`pkg2/` and `lib2/`)
1. **`lib2/std/io.lone`**:
   - Implemented `read_line() str` using WASI `fd_read` (`sys_read`) and dynamic memory allocation (`#alloc`, `#free`).
   - Implemented `parse_int(s: str) i32` handling leading whitespace and signs.
   - Implemented `random_i32() i32` and `random_range(min, max) i32` using WASI `random_get` (`sys_random`).
2. **Parser (`pkg2/lone-parser`)**:
   - Added support for explicit type annotations on `self` parameters (e.g. `self: ref<Game>`, `self: ref<Self>`) across function declarations, interface signatures, and anonymous functions.
3. **Analyzer (`pkg2/lone-analyzer`)**:
   - Hoisted struct types before method analysis to ensure constructors like `__init__() Game` resolve struct types properly instead of falling back to primitive placeholders.
   - Qualified method names in `IMPL_DEC` (`targetType.String() + "." + m.Name`) preventing WASM namespace collisions across multiple implementors.
   - Permitted explicit casting between `str` and `ptr<[]u8>` / `i32`.
   - Synthesized method call arguments: automatically prepends `self` (or `&self`) when calling inherent methods on instances.
   - Enhanced generic template argument deduction to unwrap `ref<T>` and `ptr<T>` parameters.
4. **WIR Lowerer (`pkg2/lone-compiler-wir`)**:
   - Member access function calls resolve qualified callee names (`$Struct.method`).
   - String interpolation scratch buffer switched to heap allocation (`$__lone_rt_alloc` / `$__lone_rt_free`), eliminating stack pointer corruption of caller frame slots.
   - Added sub-word load/store ops (`i32.load8_u`, `i32.load8_s`, `i32.store8`, `i32.load16_u`, `i32.load16_s`, `i32.store16`) in `loadOpForType` and `storeOpForType`.
   - String indexing `s[i]` on `TypeStr` emits byte loads (`elemSz = 1`, `i32.load8_u`).
   - Automatic generation of WASI Preview 1 imports (`fd_write`, `fd_read`, `fd_close`, `proc_exit`, `random_get`) when syscalls are used.
